# Puzzles

A collection of probability, combinatorics, graph, and algorithm puzzles solved with short explanations and Python notebooks.

## Run the notebooks

Use Python 3.9 or later. From this directory, create a virtual environment, install the dependencies, and start Jupyter.

```powershell
py -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\jupyter notebook
```

On macOS or Linux:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter notebook
```

The notebooks use the Python standard library, plus NumPy and Matplotlib for numerical and plotting examples. The Bridge and Torch notebook uses only the standard library.
